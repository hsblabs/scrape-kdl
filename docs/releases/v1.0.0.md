# scrape-kdl v1.0.0 release notes

Status: unpublished draft. Do not present this document as evidence that a tag, package, or release exists.

v1.0.0 establishes the Go reference implementation and the TypeScript implementation of the Scraping KDL `2026-07-15` language and Validated IR contracts. It includes the Go library, Go-only CLI, TypeScript ESM library, official go-rod and Playwright adapters, executable examples, shared conformance manifests, and cross-runtime HTTP/browser extraction.

The stable support matrix is Linux and macOS on amd64 and arm64, Go 1.26+, Node.js 26+, and Chromium for browser execution. Playwright Firefox and WebKit results are reported as best effort. Windows is out of scope.

Security defaults include explicit JavaScript opt-in, URL policy checks before initial and redirected requests/navigation, bounded response bodies, context-aware cancellation and timeouts, session secret isolation, JSON-compatible JavaScript results, and extraction-wide browser leases.

Before upgrading from an untagged draft, follow `docs/migration-to-v1.md`. The public contracts and post-publication guarantees are documented in `docs/public-api-v1.md`, `docs/cli.md`, `docs/versioning.md`, and `docs/maintenance-policy.md`.
