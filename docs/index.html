Scraping KDL

Declare extraction. Validate once. Run anywhere.

A declarative language and Go reference implementation for turning HTML extraction programs into validated, language-neutral IR and structured results.

View the repository Read llms.txt

One contract from source to result

Scraping KDL keeps parsing, validation, compilation, and execution as explicit stages. The same validated program can drive an HTTP runtime or a live browser adapter.

01 / SOURCE KDL describes acquisition, selection, values, and transforms.
02 / VALIDATE Imports, symbols, types, capabilities, and references are resolved.
03 / LOWER A deterministic Validated IR becomes the language-neutral contract.
04 / EXECUTE HTTP or browser adapters produce structured extraction results.
